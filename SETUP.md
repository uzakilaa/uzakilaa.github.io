# Портфолио Uki — как устроено

Сайт: https://uzakilaa.github.io/
Код: https://github.com/uzakilaa/uzakilaa.github.io

Все настройки в начале `script.js`, в объекте `CONFIG`.

## Обновить сайт
Измените файлы и отправьте их в репозиторий `uzakilaa.github.io` (git push или «Add file → Upload files» на GitHub).
Через 1–2 минуты изменения появятся на сайте.

## Добавить проект
В `script.js` найдите `PROJECTS` и допишите блок:

```js
{
  t: 'Название',
  d: { ru: 'Описание', en: 'Description' },
  s: 'HTML / CSS / JS',
  demo: 'https://uzakilaa.github.io/имя-репозитория/',
  code: 'https://github.com/uzakilaa/имя-репозитория',
  img: 'img/имя-репозитория.png'   // скриншот 16:10, положить в папку img
}
```

## Отзывы
- Клиенту отправляйте ссылку на Google Форму (она же в футере «Оставить отзыв»;
  старая ссылка `сайт/#review` тоже ведёт на форму).
- Ответы попадают в Google Таблицу «Отзывы uzakilaa.dev».
- Чтобы отзыв появился на сайте, впишите «да» в столбец «Одобрено».
- Блок «Что говорят люди» сам появляется, когда есть хотя бы один одобренный отзыв.
  Показываются 6 последних. Все отзывы: https://uzakilaa.github.io/reviews/

## Заявки
Сейчас форма заявки копирует текст и открывает Telegram @utiko31 (или письмо на почту).
Если захотите получать заявки ботом в Telegram — укажите адрес своего обработчика в `CONFIG.orderUrl`.
